## Overview

A fully responsive, modern website concept for a Luminary Solar. The project focuses on clean visual hierarchy, intuitive user experience, and a professional aesthetic suited to the Solar industry.

---

## Features

- Fully responsive layout across mobile, tablet, and desktop
- Modern, clean UI with consistent design system
- Smooth scroll behaviour and subtle UI transitions
- Structured page sections: hero, services, about, contact
- Semantic HTML5 markup
- Utility-first styling with Tailwind CSS
- Vanilla JavaScript — no frameworks or dependencies
- Optimised for fast load times and clean Lighthouse scores
